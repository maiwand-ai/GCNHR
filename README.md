# Geneva Center for Negotiations and Human Rights

A responsive, multilingual website for GCNHR, an independent non-profit association based in Geneva, Switzerland.

## Languages

English, French, Dari, Pashto, and Uzbek. Dari and Pashto use right-to-left page layouts.

## Run locally

From this directory, start a static web server:

```sh
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

The site uses the supplied GCNHR logo and statutes. Photography and web fonts load from external providers.
