Website admin

Sign in with a GitHub access token that can write to the website repository .

How do I get an access token?
  1. Sign in to GitHub as the owner of the repository.
  2. Open Fine-grained tokens → Generate new token.
  3. Name it, e.g. “GCNHR website”, and choose an expiry date.
  4. Under Repository access choose Only select repositories and pick the website repository.
  5. Under Permissions → Repository permissions, set Contents to Read and write.
  6. Click Generate token, copy it and paste it above. Keep it private, like a password.

Collaborators who don't own the repository can use a classic token with the repo scope instead.

Publishing

Published changes go live about 1–2 minutes after you click Publish changes. Visitors' browsers may keep the old version for up to 10 minutes. Every publish is saved in the repository history, so earlier versions can always be restored.
